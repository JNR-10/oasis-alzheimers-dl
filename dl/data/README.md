# Deep-Learning Data Directory

Raw OASIS-3 data is intentionally not version-controlled. The cohort must be obtained through the OASIS access process and used in accordance with its data-use terms. Dataset access, approval timing, usable T1-weighted scans, labels, and the number of subjects with multiple visits must be confirmed before the final cohort is fixed.

This directory may eventually contain local manifests or scripts that describe the cohort, but it must not contain MRI/NIfTI volumes, large derived datasets, checkpoints, or model weights. Keep subject identifiers and paths in local, ignored files where required by the data-use terms.
